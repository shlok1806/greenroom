# greenroom

A machine for AI coding agents to build, run, click through, and verify their work on.
macOS first.

Read [docs/00-idea.md](docs/00-idea.md) for the idea and the open questions.

## Develop

```sh
pnpm install
pnpm lint
pnpm typecheck
pnpm test
```

Layout: `apps/` for deployables, `packages/` for shared libraries, `docs/` for notes
and decision records.
